# Helping with Interface

Bug reports are welcome via GitHub Issues: something that does not work on your Mac, an
agent pane that misbehaves, an update that failed.

When opening an issue, please include:

- Your Mac model and macOS version
- The Interface version (Settings > Updates)
- Which agent tool and version it concerns (`claude --version`, `codex --version`)
- What you did, what you expected and what happened
- If it helps, the report from Help > Copy Diagnostics. It leaves out credentials, but read
  it before posting and remove prompts, file names and anything else private.

Andre directs development with AI assistance and accepts feedback through issues only.
Outside pull requests are turned off because Andre does not review outside code changes.

For a suspected security vulnerability, please use the private reporting instructions in
[SECURITY.md](SECURITY.md).
