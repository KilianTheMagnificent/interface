## T3 Code (TN Code fork)

The Threads look (owner, 2026-11-16) was adapted from the Apple-style
stylesheets of TN Code, the owner's fork of [T3 Code](https://github.com/pingdotgg/t3code):
its measurements, label and fill tiers, grouped cards, the prompt bubble and
its tail shape, the composer card and the sidebar rows and tiles. No T3 Code
name, logo or other brand asset is used. Carried by `electron/src/renderer/theme.css`
(the `--tn-*` tokens), `components/ThreadTranscript.css`,
`components/ThreadComposer.css`, `components/ThreadPaneHead.css` and
`components/ThreadInbox.tsx`.
