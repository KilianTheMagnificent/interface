# Hands-free UI testing

Drive the real app without the owner's mouse, keyboard, focus, clipboard or data. Never point Computer Use, `screencapture`, `osascript` or `open` at Interface, and never start the installed apps.

    npm --prefix electron run handsfree   # builds host + bundles; returns once the hidden app's renderer is loaded
    cd electron; hf() { node scripts/handsfree.mjs "$@"; }   # later commands run from electron/ (or pass --session)
    hf wait '.workspace-toolbar'; hf click '.terminal-launcher-profile.is-shell'; hf click --text 'Launch 1 shell terminal'
    hf eval "window.iface.listTerminals().then(s => { const t = s.terminals[0]; window.iface.sendTerminalInput(t.id, t.generation, new TextEncoder().encode('ls -la ~\r')); })"
    hf shot /private/tmp/x.png; hf focus; hf logs; hf stop   # Read the PNG

`HANDSFREE=1` (`electron/src/main/handsfree.ts`, vendored kit hook `electron/scripts/handsfree-electron.cjs`) keeps the window hidden but painting and muted, holds userData, host data, HOME and Foundation preferences in the session, gives pages and main an in-memory clipboard, removes the default menu, and refuses OS permissions; packaged builds refuse it. Every provider CLI (Claude, Codex, Grok, Qwen, Antigravity, OMP, OpenCode, qwen-mlx-server) is `electron/scripts/handsfree-fake-provider.sh`: host PATH is the session bin plus system directories, and the session `.zprofile` puts that bin first again in login shells.
Claude started for a structured session (Threads, chat, agents: stream-json in and out) is the scripted fake `electron/scripts/handsfree-fake-claude.mjs` instead, run on the checkout's Electron as Node: it offers fake models, honours `--session-id`, `--resume`, `--fork-session` and `--resume-session-at`, writes real transcripts under the session HOME's `.claude/projects` (under `$CLAUDE_CONFIG_DIR/projects` when the launch sets it, as an added Claude account does), and makes one edit per prompt in the working directory. Prompt verbs: `write <path> <text>` creates or overwrites the file, `append <path> <text>` adds a line, anything else is appended to `HANDSFREE-NOTES.md`; `slow` waits about 3 s first (a working state), `ask` raises an approval first (shown when the session's permission mode asks), `burst` streams the reply the way Opus does (a dozen deltas at once, about once a second), `signedout` fails the turn the way a signed-out Claude Code does. `limit <seconds>` fails the turn the way a rate-limited Claude Code does (a rejected `rate_limit_event` whose `resetsAt` is that many seconds ahead, then the "You've hit your limit" reply and an error result) and refuses every later prompt in that process until then (Resume at reset, T3 §10; `limit 0` refuses only its own turn). Team tools: `team start <task>` starts a thread through the `iface_team` server its `--mcp-config` names (`start_thread`, then `wait_thread`) and answers with that thread's answer; `team wait [<thread>]` waits for the last one it started; `team schedule <minutes> <prompt>` schedules a prompt to its own thread (`schedule_prompt`, T3 §7). Visual replies: `visual <title>` calls `show_visual` with a small chart page (an inline script draws it) and then answers in words; the thread needs a project (pin one with `window.iface.setAppearance({version:1, pinnedProjects:['<git folder>']})` and reload). Private secrets: `secret <name> [<reason>]` calls `request_secret` and waits for the card; given, it reads the file it is pointed at and says the value's length (never the value); declined, it says so. A one-shot print call (`-p --output-format json`, as `title.rs` makes it) answers one JSON result: a title, or for Write with AI a commit message or pull request text naming the files in its input's `<changes>`; the session bin has no `gh`, so put a stub there (`<session>/profile/bin/gh` answering `auth status` and `pr list`) to see Push & open PR's form. Team tools' per-session sockets live under `/private/tmp/iface-tt-*`, so they work in the kit. An Away loop's prompt gets the `AWAY_RESULT` line Away reads: a work round appends to `HANDSFREE-NOTES.md` and says continue; a review edits nothing and says continue, then complete on the last round (so a two-round loop finishes; a project Away needs a git repository, e.g. `git init` the session HOME). `claude auth status --json` answers signed in, or signed out while the session HOME (`<session>/profile/home`) holds `.handsfree-signed-out`. Put `slow`/`ask`/`burst` before the verb: the text runs to the end of the line. A tool-less chat (No project) and plan mode only reply.
Grok started over ACP (its flags, then `agent stdio`) is the scripted ACP agent `electron/scripts/handsfree-fake-acp.mjs`, also on the checkout's Electron as Node: one fake model, `session/new` and `session/load`, and per prompt a short reply and one edit in the session's folder through an `edit` tool call (`write`/`append`/anything else as the fake Claude; `slow` waits about 3 s, `ask` asks permission first). With it a project thread can switch between Claude and Grok (T3 §5).
Refused with a `handsfree: blocked` log line and an error in the UI: the New pane menu's Files, Browser and iOS Simulator; Open in external terminal; revealing an agent home; the voice assistant (microphone and speakers; the host's voice helper is `/usr/bin/false`); enabling or pairing phone remote access (LAN listener).
Terminal panes run xterm in screen-reader mode, so `type` never reaches them and `key` sends only letters, digits, Space and Enter (other keys such as `-` send wrong key codes and corrupt the line): write pane input with `sendTerminalInput` as above. `type` works in ordinary inputs.
Out of reach: vibrancy as composited, Dock, menu bar, native dialogs (auto-cancelled), notifications, Finder drag-and-drop, live providers, cross-model collaboration (the session path exceeds the 103-byte socket limit) and paired phone states (`npm run smoke:remote` covers those with a real host).
Cost: `node scripts/handsfree-cost.mjs [seconds]` (from `electron/`) prints what the hidden app uses of one processor core in its current state, by process, with the page's main-thread share and any compositor layer drawn again while it watched. It is how a battery change is measured (looks, 2026-11-15); a hidden window is not a real display, so compare runs with each other and repeat one before trusting a difference under two points.
TUI: `npm --prefix electron run handsfree:tui -- start` builds `iface` and runs it in a private tmux server with the same fakes and a throwaway HOME/`IFACE_DATA_DIR`; drive with `tmux -S <socket> send-keys -t iface ...` and `capture-pane -p -t iface`, end with `-- stop`.
Renderer lanes (`node scripts/test-renderer-dom.mjs`, `scripts/*-lane.cjs`) are not the hands-free kit: their windows use the real system clipboard, so a lane or probe must never read or write it (a probe overwrote the owner's clipboard on 2026-11-15); stub the copy hook as the Browser lane does.
Keep `electron/scripts/handsfree.mjs` and the hook byte-identical to `~/Developer/Projects/_AI/Tools/handsfree` (`cmp`).
